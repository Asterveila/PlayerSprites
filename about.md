# PlayerSprites
<cb>The spiritual successor to Sonic Robot Mod.</c>

PlayerSprites is a mod that allows you to replace any gamemode in GD with a <cy>**working Sprite Animation**</c> of any character from any game you want! *(Granted, if they have sprites, of course.)*
Sprite animations work globally, on any level, any gamemode! Entirely driven through the use of <cj>**Sprite Packs**</c>, anyone can import any sprite animation into the game to play on any gamemode!

*(Don't worry, the mod has a few Sprite Packs built-in!)*

To get started, head over to the <cg>**Icon Kit Menu**</c>, look on the left side for a <cj>blue square button</c>. Once you find it, that button can open the mod's own Custom Popup!
If it's your first time using the mod, it'll ask you to install the built-in packs to your game, so you can immediately start playing and using PlayerSprites without the need of making your own pack first!

## Mod Features
- <cs>**Event-based animations**</c>: Different sprite animations can play on any in-game event, such as Running, Jumping, Dashing, hitting an Orb, using a Pad, just about anything you can think of!
- <cs>**Replace any gamemode**</c>: The mod allows you to replace ANY gamemode in the game with your own desired sprite animations! You, as the user, are also able to individually toggle each gamemode for each pack on/off to your liking!
- <cs>**Both Level Types support**</c>: Packs can be enabled/disabled per Level Type, so you can keep some on for Classic levels while having other packs on for Platformer levels!
- <cs>**Robust Pack customization**</c>: If you're creating a Sprite Pack, you're able to customize pretty much every aspect of it! Add as many animations as you want, for specific gamemodes, set each animation's frame count, duration, if it should loop, their scale, etc!
- <cs>**Per-Pack control**</c>: As the end user, you're able to individually toggle full packs on/off, or just toggle their individual animations per-gamemode with ease! Don't like the Cube's orb animation in a pack but don't wanna disable the entire gamemode? Yup, can do too! Everything is controllable via the mod's own custom menu!
- <cs>**SFX Packs**</c>: Yeah, the mod is called Player**Sprites**, but Packs can also add Sound Effects to go along with them! Of course, these are also fully controllable via the mod's own menu.
- <cs>**Easy Pack Importing**</c>: Via the mod's custom menu, you're able to import any sprite packs easily simply by clicking a button! Sprite packs are distributed as *.zip* files. As a pack creator, you're also able to easily Export your created packs with a single click!

## How?
PlayerSprites allows you, the user, to create and load <cy>**"Sprite Packs"**</c>, the mod's own "Texture Pack" format.
Sprite packs contain a variety of individual sprites as images, as well as one json file that defines when each set of sprites gets played out like an animation in the game!
Wanna have an animation for walking, one for jumping, another one for falling and one for dashing? Can do!
Oh, and if you wanna make a pack that doesn't *replace* vanilla icons, but rather <cl>adds an overlay</c> to them, that's possible, too! There's a sprite pack example for this included in the mod.
Oh, and yup. You can make animated icons now. ~~Technically.~~ You're welcome.

Not only that, but you can <cl>load multiple Sprite Packs at a time</c>, enable some of them, disable others, keep one pack active for one gamemode and keep others enabled on other gamemodes, all of that and more is completely possible!

We've already mentioned how to open up the mod's custom menu, so you should know how to do that! From the popup, you'll be able to find everything you need to control Sprite Packs to your liking. You can:

- <cg>Enable/Disable</c> entire packs, no texture reloads or game restarts required
- <cj>Import</c> **any** Sprite Pack easily
- <cp>Live preview</c> of ALL loaded animations from the pack
- <cg>Enable/Disable</c> per-gamemode animations
- <cg>Enable/Disable</c> individual animations
- <cg>**Entirely** enable/disable</c> pack for Classic/Platformer mode only
- <cg>Enable/Disable</c> SFX for the pack
- <cp>Preview</c> and <cg>Enable/Disable</c> individual SFX

*(All settings are per-pack, so you can keep some stuff on from one pack, and some from another!)*
